## 👋 About Me

I'm **Omkar Hundre**, a Software Engineer from India interested in backend engineering, system design and cloud infrastructure.

I've worked on **9 production software products for 8 corporate clients**, across AI automation, manufacturing ERP, EdTech and real-time applications.

My work involves building backend services, designing database structures, implementing APIs and real-time communication, optimizing application performance and deploying software to production.

**A few things I've worked on:**

- ⚡ Reduced API latency by **40%** using Redis caching.
- 🏭 Built an offline-first industrial ERP that reduced quotation processing from **7 days to under 5 minutes**.
- 🤖 Developed a Python-based AI recruitment system that reduced batch resume screening from hours to **under 10 minutes**.
- ☁️ Managed application deployments and infrastructure across VPS environments.

I'm particularly interested in understanding how systems communicate, where bottlenecks emerge and how to build software that remains reliable as it grows.

## 🚀 Featured Projects

### 🤖 OLAI — Visual AI Workflow & Agent Execution Engine

A node-based platform for designing and executing AI workflows without writing the entire orchestration logic manually.

- Visual DAG-based workflow builder
- Asynchronous workflow execution
- Multi-step AI agent and tool-calling workflows
- Sandboxed Python/FastAPI and Node.js runtimes
- Schema validation and workflow execution

**Stack:** Python, FastAPI, TypeScript, React, Node.js, Redis

[Live Demo](https://olai-orchestration.netlify.app) · [Source Code](https://github.com/Omkar-Hundre/Olai.git) · [Video Demo](https://youtu.be/wNOn777NxqQ)

### ⚙️ COSEM — Industrial Quotation & ERP Engine

An offline-first industrial software platform built to automate complex cost estimation and quotation workflows for manufacturing companies.

- Reduced quotation processing from 7 days to under 5 minutes
- Deployed across 5 manufacturing companies
- Processed 100+ production orders
- Supports nested assemblies and dynamic pricing
- Local SQLite storage with background synchronization

**Stack:** Python, Electron.js, React, PostgreSQL, SQLite, JavaScript
